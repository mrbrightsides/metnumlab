### **Q9: Students bilang platform tidak load / error / stuck. Apa yang harus saya lakukan?**

**A:** Systematic troubleshooting:

**STEP 1: Identify Problem**
```
Ask student:
- Apa exact error message?
- Kapan terjadi? (login, processing, export?)
- Screenshot bisa?
```

**STEP 2: Common Solutions**

| Problem | Solution |
|---------|----------|
| "Page won't load" | Refresh browser (F5) |
| "Job stuck processing" | Check input format (CSV valid?) |
| "Export doesn't work" | Allow pop-ups in browser |
| "Can't login" | Clear browser cache |
| "Slow performance" | Close other tabs |

**STEP 3: Browser Issues**
```
Try different browser:
- Chrome (recommended)
- Firefox (good)
- Safari (ok)
- Edge (ok)
- Internet Explorer (NO! Too old)
```

**STEP 4: Device Issues**
```
Minimum requirements:
- Any laptop/desktop from last 5 years
- 4GB RAM (8GB better)
- Modern browser
- Stable internet (1 Mbps minimum)
```

**STEP 5: Contact Support**
```
If still not working:
- Email: support@rantai-metnumlab.com
- Include: screenshot, error message, browser/device info
- Response within 24 hours
```

**Pro Tip:**
Have 1-2 "tech-savvy" students as helpers. They can troubleshoot peer issues while you focus on teaching.

### **Q12: Apakah platform replace need for manual calculations?**

**A:** **NO! Manual calculation tetap penting!**

**Philosophy:**
> "Platform is a TOOL, not a REPLACEMENT for understanding."

**Recommended Approach:**

**Stage 1: Learn Manually (Weeks 1-2)**
```
- Teach theory thoroughly
- Work examples on whiteboard
- Students calculate by hand
- Understand WHY method works
```

**Stage 2: Verify with Platform (Weeks 3-4)**
```
- Do manual first
- Then use platform to check
- Compare results
- Understand error sources
```

**Stage 3: Apply to Complex Problems (Weeks 5+)**
```
- Manual too tedious for big problems
- Platform enables realistic applications
- Focus shifts to interpretation
- Students see power of computational tools
```

**Assessment Balance:**
- Exams: Some manual calculation questions (test understanding)
- Homework: Platform-based (test application)
- Project: Platform + manual verification

**Real Example:**
```
Exam Question:
"Do 2 iterations of Newton-Raphson manually for f(x) = x² - 2, x₀ = 1.
Then explain when you would use platform vs manual calculation in practice."

This tests both understanding AND judgment!
```

### **Q17: Apakah students need to create account / login?**

**A:** **NO LOGIN REQUIRED!** 🎊

**Anonymous Use:**
- Open website → Start using immediately
- No email, password, registration
- Data stored locally in browser
- Complete privacy

**Why No Login?**
- Remove barriers to access
- Faster onboarding
- No password hassles
- Focus on learning, not admin

**Trade-off:**
- Data not synced across devices
- If clear browser data → jobs lost
- No cloud backup

**Recommendation:**
Students should:
- Use consistent device
- Export important jobs as PDF/CSV
- Keep local backups

**Future Feature:**
Optional account for users who want:
- Cloud sync
- Cross-device access
- Job history
- But still not required!
